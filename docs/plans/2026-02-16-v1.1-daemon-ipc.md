# v1.1 Daemon + IPC Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the foreground `hush listen` command with a background daemon that accepts IPC commands via Unix socket, enabling compositor keybindings and eliminating the "keep a terminal open" requirement.

**Architecture:** A Unix socket server (`/run/user/UID/hush.sock`) runs inside the existing `handle_listen` event loop. A thin IPC client sends JSON commands. The daemon is the same binary — `hush daemon start` forks to background, `hush toggle` connects and sends a command. PID file enforces singleton.

**Tech Stack:** `tokio::net::UnixListener` for async IPC, `serde_json` for protocol, `daemonize` crate for forking, `nix` for signal handling. All already in the dep tree or trivially added.

/// Write current process PID to the PID file.
/// Returns error if another daemon is already running.
pub fn acquire_pid_lock() -> Result<()> {
    let path = pid_path();

    // Check if existing PID file points to a running process
    if path.exists() {
        if let Ok(contents) = std::fs::read_to_string(&path) {
            if let Ok(pid) = contents.trim().parse::<i32>() {
                // Check if process is alive via kill(pid, 0)
                let alive = unsafe { libc::kill(pid, 0) } == 0;
                if alive {
                    anyhow::bail!(
                        "Another hush daemon is already running (PID {}). \
                         Use 'hush daemon stop' to stop it first.",
                        pid
                    );
                }
            }
        }
        // Stale PID file — remove it
        let _ = std::fs::remove_file(&path);
    }

    let pid = std::process::id();
    std::fs::write(&path, pid.to_string())
        .with_context(|| format!("Failed to write PID file: {}", path.display()))?;
    Ok(())
}

use std::sync::Arc;
use anyhow::{Context, Result};
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use tokio::net::UnixListener;
use tokio::sync::mpsc;
use tracing::{debug, error, info, warn};

use super::paths;
use super::protocol::{DaemonCommand, DaemonResponse};

/// Handle to send responses back to connected clients.
/// The daemon's main loop uses this to push state updates.
pub type ResponseSender = mpsc::Sender<DaemonResponse>;

/// Receives commands from IPC clients.
pub type CommandReceiver = mpsc::Receiver<DaemonCommand>;

/// Start the IPC server. Returns a channel for receiving commands from clients.
///
/// The server runs in a background tokio task. Each client connection
/// sends one command, receives one response, and disconnects.
pub async fn start_ipc_server() -> Result<(CommandReceiver, Arc<IpcServer>)> {
    paths::ensure_runtime_dir()?;
    paths::cleanup_socket();

    let sock_path = paths::socket_path();
    let listener = UnixListener::bind(&sock_path)
        .with_context(|| format!("Failed to bind socket: {}", sock_path.display()))?;

    info!("IPC server listening on {}", sock_path.display());

    let (cmd_tx, cmd_rx) = mpsc::channel::<DaemonCommand>(32);
    let server = Arc::new(IpcServer {
        response: tokio::sync::Mutex::new(DaemonResponse::Idle),
    });

    let server_clone = server.clone();
    tokio::spawn(async move {
        loop {
            match listener.accept().await {
                Ok((stream, _addr)) => {
                    let cmd_tx = cmd_tx.clone();
                    let server = server_clone.clone();
                    tokio::spawn(async move {
                        if let Err(e) = handle_client(stream, cmd_tx, &server).await {
                            warn!("IPC client error: {}", e);
                        }
                    });
                }
                Err(e) => {
                    error!("IPC accept error: {}", e);
                }
            }
        }
    });

    Ok((cmd_rx, server))
}

/// Shared state that the daemon updates so IPC clients can query it.
pub struct IpcServer {
    response: tokio::sync::Mutex<DaemonResponse>,
}

impl IpcServer {
    /// Update the current state (called by daemon main loop).
    pub async fn set_state(&self, response: DaemonResponse) {
        *self.response.lock().await = response;
    }
}

async fn handle_client(
    stream: tokio::net::UnixStream,
    cmd_tx: mpsc::Sender<DaemonCommand>,
    server: &IpcServer,
) -> Result<()> {
    let (reader, mut writer) = stream.into_split();
    let mut reader = BufReader::new(reader);
    let mut line = String::new();

    reader.read_line(&mut line).await
        .context("Failed to read from IPC client")?;

    let command: DaemonCommand = serde_json::from_str(line.trim())
        .with_context(|| format!("Invalid IPC command: {}", line.trim()))?;

    debug!("IPC received: {:?}", command);

    // For status queries, respond immediately with current state
    let response = match &command {
        DaemonCommand::Status => server.response.lock().await.clone(),
        DaemonCommand::Stop => {
            cmd_tx.send(command).await.ok();
            DaemonResponse::Stopping
        }
        _ => {
            cmd_tx.send(command).await
                .context("Daemon command channel closed")?;
            // Return current state as acknowledgment
            server.response.lock().await.clone()
        }
    };

    let mut response_json = serde_json::to_string(&response)?;
    response_json.push('\n');
    writer.write_all(response_json.as_bytes()).await
        .context("Failed to write IPC response")?;

    Ok(())
}

/// Send a command to the running daemon and return its response.
pub async fn send_command(command: DaemonCommand) -> Result<DaemonResponse> {
    let sock_path = paths::socket_path();

    let stream = UnixStream::connect(&sock_path).await
        .with_context(|| {
            format!(
                "Cannot connect to hush daemon at {}. Is it running?\n\
                 Start it with: hush daemon start",
                sock_path.display()
            )
        })?;

    let (reader, mut writer) = stream.into_split();

    let mut cmd_json = serde_json::to_string(&command)?;
    cmd_json.push('\n');
    writer.write_all(cmd_json.as_bytes()).await
        .context("Failed to send command to daemon")?;
    writer.shutdown().await.ok();

    let mut reader = BufReader::new(reader);
    let mut line = String::new();
    reader.read_line(&mut line).await
        .context("Failed to read response from daemon")?;

    let response: DaemonResponse = serde_json::from_str(line.trim())
        .with_context(|| format!("Invalid daemon response: {}", line.trim()))?;

    Ok(response)
}

/// Check if the daemon is running by attempting to connect to the socket.
pub async fn is_daemon_running() -> bool {
    let sock_path = paths::socket_path();
    UnixStream::connect(&sock_path).await.is_ok()
}

    });

    let mut session = ListenSession::new(config).await?;

    // Main loop: handle both IPC commands AND hotkey events
    loop {
        tokio::select! {
            Some(cmd) = cmd_rx.recv() => {
                match cmd {
                    DaemonCommand::Toggle => session.toggle().await?,
                    DaemonCommand::Cancel => session.cancel().await?,
                    DaemonCommand::Stop => break,
                    DaemonCommand::Reload => session.reload_config().await?,
                    DaemonCommand::Status => {} // handled by server
                }
                // Update IPC server state
                ipc_server.set_state(session.current_response()).await;
            }
            event = session.next_event() => {
                // Handle hotkey events, transcription results, etc.
                session.handle_event(event).await?;
                ipc_server.set_state(session.current_response()).await;
            }
            _ = &mut shutdown => break,
        }
    }
}
```

The exact implementation depends on how ListenSession is structured, but the pattern is: IPC commands and hotkey events both feed into the same session.

**Step 3: Update IPC state on every transition**

After each state change (idle → recording → transcribing → inserting → idle), call `ipc_server.set_state()` with the appropriate `DaemonResponse`.

//! Integration tests for daemon IPC.
//! These tests start a real daemon process and communicate with it.

use std::process::{Command, Stdio};
use std::time::Duration;

#[tokio::test]
async fn test_daemon_lifecycle() {
    let exe = env!("CARGO_BIN_EXE_hush");

    // Start daemon in foreground (in background thread)
    let mut daemon = Command::new(exe)
        .args(["daemon", "start", "--foreground"])
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .expect("Failed to start daemon");

    // Wait for socket to appear
    tokio::time::sleep(Duration::from_secs(2)).await;

    // Query status
    let output = Command::new(exe)
        .args(["status"])
        .output()
        .expect("Failed to run status");
    assert!(output.status.success());

    // Stop daemon
    let output = Command::new(exe)
        .args(["daemon", "stop"])
        .output()
        .expect("Failed to stop daemon");
    assert!(output.status.success());

    // Wait for daemon to exit
    let _ = daemon.wait();
}
```
