# Store screenshots

The metainfo shows these two in Flatpak stores, because a store user gets portal mode, where the desktop holds the keys and types the text. They come from the Flatpak in a Fedora 45 VM with KDE Plasma, through `HUSH_SETTINGS_SCREENSHOT` and the sample history and vocabulary of `scripts/screenshots.sh`, with the frame that `screenshots.sh` adds. The other store screenshots (Speech, History, and the command palette) look the same in both modes, so the metainfo takes them from `../settings`.
