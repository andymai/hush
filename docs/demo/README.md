# Demo

The site plays `hush-demo.webm`, or `hush-demo.mp4` in a browser without WebM. The README plays `hush-demo.gif`. The three files show the same 30-second take: a commit message in Konsole, a review comment on a web page, and a message on a chat page.

They come from the Flatpak 1.20.3 in a Fedora 45 VM with KDE Plasma, in portal mode with the Ctrl+Super+Space key. A Piper voice (`en_US-lessac-medium`) speaks each sentence into a virtual microphone while a script holds the key. Hush types each sentence. The script types `git commit -m "`, the closing quote, and each Enter.

The cuts remove only the time that each application takes to open. Each dictation plays at its real speed.
