Hold a key, talk, and your words appear wherever you're typing.

Local dictation for Linux. Whisper runs on your own computer, so your voice stays with you.

Install Hush Source on GitHub

Works where you type

Terminals, browsers, editors, and chat. The packages type through the kernel, so they work on any Wayland or X11 desktop. The Flatpak works on KDE Plasma 6 and GNOME 48 or later.

Stays on your computer

Whisper runs on your own GPU, or on the CPU when you have none. Your audio never leaves unless you pick a cloud service yourself.

Writes like you

Casual in chat, full sentences in email, lowercase in the terminal. Teach it a name once and it spells it your way. Select text, hold the Command key, and say "make this friendlier".

Install

Flatpak

For KDE Plasma 6 and GNOME 48 or later. Download the install file, then open it with your software center, or run:

flatpak install --from https://andymai.github.io/hush/io.github.andymai.hush.flatpakref

Your desktop sets the hotkeys and asks once for keyboard access. On Sway, Hyprland, and other wlroots desktops, use a package below: the Flatpak can't type there.

Fedora

sudo dnf copr enable veroz/hush && sudo dnf install hush

Ubuntu, Debian, and other distributions

Get the .deb, .rpm, AppImage, or tarball from the latest release. Or let the install script pick the right one and check its checksum:

curl -fsSL https://raw.githubusercontent.com/andymai/hush/main/install.sh | sh

NixOS

nix profile install github:andymai/hush

Prebuilt files are for x86-64. INSTALL.md covers each method, download checks, and builds from source.
